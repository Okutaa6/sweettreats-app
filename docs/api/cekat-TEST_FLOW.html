Bug Reporting Template

Kalau ada test yang fail, laporkan dengan format:

Test ID    : T-X.X
Environment: Lokal / Produksi (sandbox / live)
Request    : [method + URL + body]
Expected   : [yang seharusnya]
Actual     : [status code + body response]
Cek DB     : [hasil query verifikasi kalau relevan]
Catatan untuk tester:
  1. Semua tes tulis pakai endpoint sandbox (/apicekatdev/*) → masuk tabel _dev, aman.
  2. Verifikasi DB: phpMyAdmin atau php artisan tinker (contoh query ada di tiap test).
  3. Beberapa test E berurutan (slot habis bergantung test sebelumnya).
  4. Token bocor jangan di-commit. docs/api/cekat-api.http harus tetap pakai placeholder saat masuk git.
