Cara pakai dokumen ini: Klik tombol Pass atau Fail di setiap test. Progress otomatis ke-save di browser (LocalStorage). Bisa di-export hasil tes via tombol "Export Result" di sidebar, atau di-print sebagai PDF.

Pre-Requisites

1. Run SQL files (urutan penting!)

Login ke phpMyAdmin pada DB production, jalankan file-file berikut berurutan dari folder database/sql/:

#FileApa yang dilakukan
12026_05_02_marketing_promo.sqlBikin tabel marketing_promo, marketing_promo_branch + kolom marketing_promo_id di reservasi
22026_05_02_referral_scope.sqlTambah kolom referral_scope ke raw_affiliate & raw_promo
32026_05_02_reward_program_lock.sqlTambah kolom reward_program_started_at
42026_05_02_quick_fixes.sqlUpdate Gold tier 13→15 + tambah behel_type
52026_05_02_kol_detail.sqlTambah 8 kolom KOL (kategori, progress, dll)
62026_05_02_commission_claim.sqlBikin tabel commission_claim_batch & commission_claim_item
Semua SQL idempotent — kalau sudah pernah dijalankan, akan skip otomatis (tidak error). Aman di-rerun.

2. Setup Sidebar Menu (manual via UI Admin)

Setelah SQL selesai, daftarkan 2 menu baru via Setting → Akses Menu (/setaccess):

MenuLinkIconUntuk Grup
Promo (Marketing)marketing-promofa fa-tagSales, Head Sales, Admin
Klaim Komisicommission-claimfa fa-hand-holding-dollarCreative, Admin, Finance

Lalu rename menu lama: edit menu yang link-nya rawpromo → ubah Nama dari "Promo" → "Kode Referral".

Setelah daftarin di access path, masuk ke Setting → Grup User (/setgroup), kasih akses 2 menu baru ke grup yang relevan.

3. Test Account

Pastikan tester punya:

  • Akun admin dengan akses penuh (super admin / admin)
  • Akun affiliate test (kalau belum ada, buat via flow di Fase 2A)
  • Min. 1 cabang & 1 dokter sudah ada di DB
  • Pasien dummy untuk simulasi reservasi

Bug Reporting Template

Kalau ada test yang fail, mohon laporkan dengan format:

Test ID    : T-X.X
Browser    : Chrome 120 / Firefox / dll
URL        : [URL halaman saat error]
Steps      : [langkah yang dilakukan]
Expected   : [yang seharusnya]
Actual     : [yang terjadi]
Screenshot : [attach kalau ada]
Console err: [F12 → Console tab, copy error]
Catatan untuk tester:
  1. JANGAN test di production langsung — minimal staging environment.
  2. Backup DB sebelum test — beberapa test bikin data baru.
  3. Test sequential — beberapa test depend on previous test.
  4. Buka DevTools Console (F12) untuk lihat error JS kalau ada flow stuck.
  5. Pakai incognito/private window untuk multi-role (admin vs affiliate) supaya session tidak bentrok.
