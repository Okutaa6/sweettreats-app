Pre-Requisites

1. Run SQL files (urutan penting!)

Login ke phpMyAdmin pada DB production, jalankan file-file berikut berurutan dari folder database/sql/:

#FileApa yang dilakukan
12026_05_02_editorial_plan.sqlBikin tabel ep_konten_pillar, ep_konten, ep_campaign_framework, ep_campaign_week + 22 default pillar (auto-seed)

Semua SQL idempotent — kalau sudah pernah dijalankan, akan skip otomatis (tidak error).

Bug Reporting Template

Kalau ada test yang fail, mohon laporkan dengan format:

Test ID    : T-X.X
Browser    : Chrome 120 / Firefox / dll
URL        : [URL halaman saat error]
Steps      : [langkah yang dilakukan]
Expected   : [yang seharusnya]
Actual     : [yang terjadi]
Screenshot : [attach kalau ada]
Console err: [F12 → Console tab, copy error]
Catatan untuk tester:
  1. JANGAN test di production langsung — minimal staging environment.
  2. Backup DB sebelum test — beberapa test bikin data baru (konten EP, breakdown, campaign).
  3. Test sequential per Fase — beberapa test depend on previous (mis. Fase 3D test setelah ada konten regular, Fase 3E setelah ada campaign).
  4. Buka DevTools Console (F12) untuk lihat error JS kalau ada flow stuck.
  5. Kalau ada masalah dengan icon Instagram/TikTok yang tidak render → konfirmasi Font Awesome 6 CDN bisa diakses dari browser tester.
